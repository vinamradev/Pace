# PACE V1 Final

Mobile-first personal finance tracker.

## Final fixes included
- Reset Demo Data restores transactions, goals, budget and guard settings.
- Reset clears activity filters and closes open forms.
- Demo transaction dates are relative to the current month, so Reset keeps monthly calculations valid in future months.
- iOS Safari input zoom protection using 16px mobile form controls.
- Mobile Payment/Date and Goal fields constrained to their grid columns.
- Existing PACE V1 UI and functionality preserved.

## Run
```bash
npm install
npm run dev
```
